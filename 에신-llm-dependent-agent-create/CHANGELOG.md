# /llm-dependent-agent-create — LLM 의존형 에이전트 제조 공장

> **PO의 철학:**
> "가져다 쓰지 마라. 분해하고, 결함 부분은 걸러내고, 검증된 부품만 가려내 조립하라.
>  발굴 자체가 실력이 아니라 — 발굴 + 검증 + 자기 자산화까지 가는 흐름이 실력이다."

**필요한 LLM(두뇌) 의존형 AI 에이전트를 막연한 요청 한 줄에서 받아, 완성·검증된 에이전트로 출하하는 메타 스킬 — 에이전트를 만드는 에이전트.**

> **⚠️ 제조 대상 한정 (V3.0, 출하 형태 V3.13 축소):** 이 스킬은 **LLM(두뇌) 의존형 에이전트** — AI 플랫폼에 안 갇히고 자체 실행되며 LLM에 직접 의존하는 독립 에이전트 — 만 제조한다. 모든 에이전트는 **페르소나·LLM·목표·지식베이스·도구·안전 체계·자율 루프 7대 요소**로 구성된다(§「구현 7요소」). 출하 형태 = **2가지 구동 방식**(웹사이트형 / 데스크톱형). AI 플랫폼 종속형(서브에이전트)·스킬·훅은 제조 대상이 아니다 — 스킬 제조는 형제 공장 `/skill-create`가 담당한다 (둘은 같은 9-Phase 방식·같은 "분해·검증 후 조립" 철학을 공유하며, 같은 자산이 에이전트로 출하될 수도 스킬로 재포장될 수도 있는 양방향 관계다).
