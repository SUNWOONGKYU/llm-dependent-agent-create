# 이미 만든 에이전트를 화면(GUI)으로 바꾸기

**대상**: 에신(`/에신-llm-dependent-agent-create`)이나 라이트(`/에신-라이트`)로 에이전트를 이미 만들었는데, 쓰려면 검은 터미널 창에 명령을 쳐야 하는 분.

**하는 일**: Claude Code에게 지시문 하나를 주면, 그 에이전트에 브라우저로 쓰는 화면을 붙여줍니다. 기존 파일은 지우지 않습니다.

**걸리는 시간**: 에이전트 하나에 보통 10~30분. 사람은 처음에 지시문을 붙여넣고, 마지막에 화면을 눌러보기만 하면 됩니다.

---

## 1. 왜 이 문서가 생겼나

에신 V3.9 이전 규격에는 **화면을 만들라는 조항이 없었습니다.** 그래서 규격대로 잘 만들어도 이런 물건이 나왔습니다.

```
engine.py · run.py · run-once.bat · skills/*.md · history.json
```

전부 터미널에서 돌리는 형태입니다. 실제로 이런 화면을 보게 됩니다.

```
$ python agent.py
usage: agent.py [-h] {init,status,p0,p1,scan,case,quote,law} ...
agent.py: error: the following arguments are required: cmd
```

만든 사람은 씁니다. 그런데 **그 에이전트를 실제로 쓸 사람**(변호사·회계사·사무직·본인)은 파이썬을 모릅니다. 인자를 붙여 명령을 치라는 건 사실상 못 쓰게 만든 것입니다.

V3.9부터는 규격이 바뀌어서 **새로 만드는 에이전트는 화면이 기본으로 나옵니다.** 이 문서는 **그 전에 만들어 둔 에이전트**를 뒤늦게 화면으로 바꾸는 방법입니다.

---

## 2. 내 에이전트가 대상인가

아래 셋을 **모두** 만족하면 바꾸는 게 맞습니다.

| 확인할 것 | 그렇다면 |
|---|---|
| 내 PC에 폴더로 설치돼 있고 `.py` 파일이 있다 | ✅ |
| 사람이 직접 실행해서 결과를 받는다 (자동으로 혼자 도는 게 아니다) | ✅ |
| 쓸 사람이 개발자가 아니다 (또는 나 말고 다른 사람도 쓴다) | ✅ |

**안 바꿔도 되는 경우**
- 서버에서 혼자 도는 것 (감시·정기 실행·API로 불리는 것)
- 이미 웹사이트로 돼 있는 것
- 나 혼자만 쓰고, 나는 터미널이 편한 경우

---

## 3. 하는 방법 — 지시문 복붙

### 준비

1. 바꿀 에이전트 폴더를 확인합니다 (예: `C:\Dev\agents\내-에이전트\`)
2. **그 폴더를 통째로 복사해 백업**해 둡니다. 이름 뒤에 `_백업`을 붙이면 됩니다
3. Claude Code를 그 폴더에서 엽니다. **가장 쉬운 방법** — 탐색기로 에이전트 폴더를 연 뒤, 위쪽 **주소창을 클릭해 `cmd` 를 치고 엔터**를 누르십시오. 그 폴더에서 검은 창이 열립니다. 거기에 `claude` 를 치면 됩니다

### 지시문

아래 회색 칸을 **통째로 복사**해서 Claude Code에 붙여넣으십시오. `{에이전트 폴더 경로}` 자리만 본인 경로로 바꾸면 됩니다.

```
이 에이전트를 GUI 모드로 바꿔줘.

대상 폴더: {에이전트 폴더 경로}

작업 기준은 에신 스킬의 「★ V3.9 신설 — 로컬 GUI(웹) 출하 표준」이다.
~/.claude/skills/에신-llm-dependent-agent-create/SKILL.md 에서 그 절과
그 안의 「ui.py ↔ engine.py 연동 규격」을 먼저 읽고 그대로 따라라.
아래 목록은 요약이다. 원문 요건이 더 많으면 원문을 따른다.
그 파일이 이 PC에 없으면 참조를 건너뛰고 아래 요건 목록만으로 진행해라
(요건은 그 자체로 완결돼 있다).

## 만들 것
- ui.py — 로컬 웹 서버 + 브라우저 자동 실행
- ui/index.html — 화면 한 장 (CSS·JS 인라인)
- 시작.bat — 더블클릭 진입점 (ui.py 를 띄운다)
- requirements.txt — 없으면 만든다

## ui.py 요건 (8개 전부)
1. 127.0.0.1 에만 바인딩. 0.0.0.0 금지
2. 실행할 때마다 토큰을 만들어 최초 접속 후 쿠키(HttpOnly; SameSite=Strict)로
   옮기고 302 로 깨끗한 주소로 돌려보낸다
3. 기본 포트를 정하고, 쓰고 있으면 +1 씩 최대 12회 물러난다. 그래도 안 되면 임의 포트
4. 작업 폴더 밖 경로 접근은 403 으로 막는다. 업로드 파일명은 정규화한다
5. 같은 이름 파일이 있으면 덮어쓰지 말고 "이름(2).확장자" 로 저장한다
6. 탭을 닫을 때 나는 연결 끊김 오류(ConnectionResetError·BrokenPipeError)는
   조용히 삼킨다. 검은 창에 빨간 오류가 쏟아지면 사용자가 고장으로 오해한다
7. /favicon.ico 는 204 로 응답한다
8. 다 쓰고 나서 어떻게 끄는지 화면과 콘솔에 알려준다

## ui/index.html 요건 (8개 전부)
1. 외부 CDN 금지. 폰트·CSS·JS 전부 인라인 또는 시스템 내장
   (인터넷 없는 환경에서도 떠야 한다)
2. 시스템 폰트만 쓴다
3. 라이트·다크 양쪽 지원 (prefers-color-scheme)
4. 금액·수치에 tabular-nums 를 적용한다. 자릿수가 어긋나면 못 읽는다
5. 첫 화면에 이 도구가 무엇이 아닌지(유의사항) 적는다
6. 없는 의존성은 사람 말 + 설치 링크로 알린다. 에러 메시지 그대로 노출 금지
7. 자료는 끌어다 놓기 + 파일 선택 + 폴더 열기 3가지로 받는다
8. 접근성 — 글자 대비 확보, 입력칸에 라벨, prefers-reduced-motion 존중

## ui.py 와 engine.py 를 잇는 방법
- 기본은 engine.py 를 모듈로 import 해서 함수를 부른다.
  크래시 격리가 필요하면 subprocess 로 분리한다. 어느 쪽을 왜 골랐는지 README 에 적어라
- subprocess 로 했다면 ui.py 가 꺼질 때 자식 프로세스를 반드시 정리해라.
  안 그러면 백그라운드에 남는다
- LLM 호출은 수십 초가 걸린다. 요청을 붙잡고 기다리면 브라우저가 멈춘 것처럼 보인다.
  폴링이나 스트리밍 중 하나를 반드시 둬라
- 만든 엔드포인트 목록을 README 에 적어라

## 그 밖에 지킬 것
- 파이썬 표준 라이브러리만 쓴다. Flask·FastAPI·Streamlit 도입 금지

## 건드리지 말 것
- 기존 engine.py · run.py · agent.py 를 삭제하거나 뜯어고치지 마라.
  터미널로 쓰는 사람이 있다. 화면은 추가하는 것이지 대체하는 게 아니다
- 기존 결과 파일·설정·이력(history.json 등)을 지우지 마라
- 바탕화면에 아이콘이나 폴더를 만들지 마라

## 디자인
/frontend-design 또는 /ui-ux-builder-코어7 을 호출해 도메인 미감을 먼저 정해라
(그 스킬이 없는 환경이면 건너뛰고 아래 원칙을 직접 적용해라).
보라색 그라데이션·둥근 카드·그림자 같은 기본값 조합으로 만들지 마라.
이 에이전트가 다루는 분야에 맞는 형식을 빌려라
(법률이면 서면 조판, 의료면 차트, 금융이면 장부).

## 끝내기 전에
1. 시작.bat 을 실제로 실행해서 브라우저가 열리는지 확인해라
2. 화면의 버튼을 전부 눌러봐라. 무반응·오류 0건이어야 한다
3. 실제 자료를 하나 넣어 끝까지 돌려봐라
4. 라이트·다크 양쪽 화면을 캡처해서 _design/ 에 남겨라
5. 무엇을 만들었고 무엇을 안 건드렸는지 보고해라
```

## 4. 끝났는지 확인하는 법

AI가 "완료"라고 해도 **직접 확인**하십시오. 화면은 눈으로 봐야 압니다.

| 확인 | 정상 |
|---|---|
| `시작.bat` 더블클릭 | 브라우저가 저절로 열린다 |
| 화면 주소 | `http://localhost:숫자` 형태 |
| 버튼 전부 클릭 | 무반응·오류 없음 |
| 자료 넣고 실행 | 결과가 나오고, 오래 걸려도 진행 중인 게 보인다 |
| 결과 파일 | 어디 저장됐는지 화면에 나온다 |
| 창 닫기 | 어떻게 끄는지 안내가 있다 |
| 기존 방식 | `python run.py` 가 여전히 된다 |

하나라도 안 되면 Claude Code에 그대로 말하십시오. "○○ 버튼을 눌렀는데 아무 일도 안 일어난다"처럼 **본 것을 그대로** 전하면 됩니다.

## 5. 자주 나오는 문제

**"파이썬을 찾을 수 없습니다"**
파이썬이 없거나 설치할 때 PATH 등록을 안 한 것입니다. [python.org](https://www.python.org/downloads/) 에서 받아 설치하되, 설치 첫 화면의 **"Add Python to PATH"** 를 반드시 체크하십시오.

**검은 창이 떴다 바로 사라진다**
오류 메시지를 볼 새가 없는 것입니다. 폴더 주소창에 `cmd` 를 치고 엔터 → 검은 창에서 `python ui.py` 를 직접 실행하면 메시지가 남습니다. 그 내용을 Claude Code에 그대로 주십시오.

**브라우저가 안 열린다**
검은 창에 주소(`http://localhost:7001` 같은)가 찍혀 있습니다. 직접 복사해 브라우저에 붙여넣으십시오.

**"주소가 이미 사용 중"**
앞서 켠 창이 아직 살아 있는 것입니다. 검은 창을 전부 닫고 다시 시작하십시오.

**화면은 뜨는데 실행하면 오류가 난다**
「준비 상태」 칸에 무엇이 빠졌는지 나옵니다. 대개 설치가 덜 된 것입니다. 그 내용을 Claude Code에 주면 처리해 줍니다.

**한글이 깨져 보인다**
`.bat` 파일 인코딩 문제입니다. Claude Code에 "`.bat` 에서 한글이 깨진다"고 말하면 규격대로 고칩니다.

## 6. 하지 말 것

- **기존 파일을 먼저 지우고 시작하지 마십시오.** 화면은 덧붙이는 것입니다
- **백업 없이 진행하지 마십시오.** 폴더 복사 한 번이면 됩니다
- **AI가 "완료"라고 한 것을 그대로 믿지 마십시오.** 화면은 눌러봐야 압니다. 서버가 200을 준다고 버튼이 동작하는 게 아닙니다
- **여러 에이전트를 한꺼번에 시키지 마십시오.** 하나씩 끝내고 확인하는 편이 결국 빠릅니다

## 7. 바뀌는 모습

**전**
```
내-에이전트/
├── engine.py
├── run.py
├── run-once.bat
└── skills/
```
쓰려면: 터미널 열고 → 폴더로 이동 → `python run.py 어쩌고 --옵션`

**후**
```
내-에이전트/
├── ui.py              ← 새로 생김
├── ui/index.html      ← 새로 생김
├── 시작.bat            ← 새로 생김
├── requirements.txt   ← 새로 생김
├── engine.py             그대로
├── run.py                그대로 (터미널로도 계속 됨)
├── run-once.bat          그대로
└── skills/               그대로
```
쓰려면: `시작.bat` 더블클릭
