# 조립 비GUI 트랙 / 웹사이트형 (docs/32 · 에신 V4)

> Phase 6 에서 읽는다. 트랙 분기(SKILL.md §4)에서 「내부 도구·데몬·개발자 본인」 또는 「웹사이트형」으로 갈린 경우.
> GUI 트랙의 뼈대·고정표·어휘 교체·고정표 대조는 **적용하지 않는다.** 공통(docs/30)은 그대로.

## A. 비GUI 트랙 (터미널·데몬·내부 도구)
| 항목 | 요건 |
|---|---|
| 진입점 | `app/run.py` 하나. 서브커맨드 4개 고정: `start`(시작/1회 실행) · `status`(상태) · `resume`(이어서) · `stop`(정지/정리). 도메인 명령은 그 뒤에 추가 |
| 배치 파일 | `시작.bat` 은 선택. 두면 `python app\run.py start` 만 부른다(ASCII·CRLF·BOM 없음·괄호 없음) |
| 상태 | `store.py` 동일(원자 쓰기·잠금·단계 스냅샷·초기화 백업). 재개는 `resume` 이 `state.json` 에서 이어 간다 |
| LLM | 두 자리(Claude Code·Codex) 동일. probe 는 `run.py probe --live` |
| 로그 | `app/logs/YYYY-MM-DD.jsonl` 행위자 구분(사용자/시스템/AI) 동일 |
| 문서 | README 에 명령 4개 + 예시 출력. 매뉴얼 HTML 은 생략 가능(개발자 대상이면) |
| Phase 7-3 | 브라우저 클릭 대신 **명령 4개 실호출** + 출력 형식 확인. 사용자 여정 KPI = `start → 산출물 → status` |
| 데몬형 | fail-closed 기본(게시·삭제·승인·인증·결제는 확인 없이 실행 금지). 스케줄 트리거는 OS 작업 스케줄러가 `run.py start` 를 부른다 |

## B. 웹사이트형 (페이지 자체가 UI)
| 항목 | 요건 |
|---|---|
| 화면 | 사이트 규격을 따른다(뼈대·3단 고정표 적용 안 함). 단 7요소는 페이지 어딘가에 보여야 한다: 하는 일·LLM·안전 체계(무엇을 가리고 무엇을 안 하나)·진행 단계 |
| LLM | 서버 API 키(사업이 비용 부담) — 제작·검증은 여전히 구독 CLI. 포털 기본값을 로컬 에이전트에 상속하지 않는다 |
| 안전 | 가명화·fail-closed·비가역 confirm 동일. 외부 전송 경로 명세를 plan §4 에 적는다 |
