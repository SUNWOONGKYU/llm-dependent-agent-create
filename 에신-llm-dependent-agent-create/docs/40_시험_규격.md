## 3. 금지
- **글자가 근처에 있는가 시험** — 소스를 고정 글자 수로 잘라 낱말을 찾는 시험은 호출을 지워도 통과한다. 함수 본문(중괄호 짝)·라우트 경계로 자른다. 정규식 역슬래시는 `chr(92)` 로.
- **실 state 에 쓰는 시험** — `monkeypatch` 로 `store.STATE_PATH`·`BACKUP_DIR` 를 임시 폴더로 돌린다.
- **미확인을 통과로** — probe 의 `found=None` 을 False/True 로 단정하는 시험 금지.

## 4. 실행
```
set PYTHONUTF8=1
python -m pytest _개발자료/tests -q -p no:cacheprovider
```
