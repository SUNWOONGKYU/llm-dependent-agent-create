## 1b. 차분 결속 시험 규격 (★V4.12 — 이 절이 규격의 단일 출처, 판정·반려 조건은 `docs/50` §7-4b-2)

**적용**: 비가역 도구(게시·삭제·결제·전송)가 하나라도 있을 때만. 없으면 `해당없음`(시험 불필요). 있는데 이 시험이 없거나 `pytest.skip`·`NotImplementedError` 뼈대로 남아 있으면 V1 반려(grep 존재 검사 — 함수 이름 `test_binding_differential*`).

**무엇을 재나**: 승인 뒤에 "결과를 바꿀 수 있는 입력"을 하나씩 바꿔 최종 전송 직전 payload 를 덤프했을 때, payload 가 승인 시점과 달라졌는데도 그 승인으로 전송되면 실패다. 정적 대응표(작성자가 "묶었다"고 적은 것)가 아니라 **실행해서 측정**한다 — 대응표 행은 있는데 범위가 좁은 결함(실사고: 승인 해시에서 발신자·답장 주소 누락)은 대응표로는 안 잡힌다.

**규격 8항**
1. **fake 전용** — LLM 도 transport(마지막 소켓·HTTP 호출)도 fake. 실키·실호출·실발송 없음(`docs/50` 7-2 "쓰지도 않을 키·비용 때문에 출하가 막히면 안 된다" 원칙 그대로). 실제 전송 경로 코드는 그대로 실행하고 **마지막 transport 만** 가짜로 교체한다.
2. **입력 목록은 코드에서 기계 추출한다 — 작성자 표에서 가져오지 않는다**(자기참조 재발 방지). **키 표기 규칙** — `env:<환경변수명>` · `profile:<프로필/설정 필드명>` · `draft:<초안 필드명>` 접두어 + 이름 그대로(예: `env:RESEND_KEY`, `profile:reply_to`). `TABLE_FIELDS`·`EXEMPT` 의 키도 같은 표기를 쓴다. 추출 대상: (a) 프로필·설정 키 전체(예: `PROFILE_FIELDS` 류 상수·설정 화면이 받는 필드) (b) `.env`·환경변수 키 전수(`os.environ`·`os.getenv` grep) (c) 초안 필드 전체(제목·본문·수신자·첨부 등). F1 닫힌 목록·대조표 11행의 표는 **보충용**이다 — 표에 있는데 추출에 없거나 그 반대면 불일치로 V1 반려. 비교에서 빼는 입력은 시험 안 `EXEMPT` 딕셔너리에 **사유와 함께**만 적는다(사유 빈 문자열 = 시험 실패).
3. **입력마다 두 번 바꾼다** — "다른 유효 값"과 "빈 값"(빈 값이면 필드 자체가 payload 에서 빠지는 경로가 열린다).
4. **주입 시점 두 곳** — (a) 승인 직후·발송 전 (b) 다수 발송 중 **두 번째 건 transport 직전**(루프가 설정을 시작 시 1회만 읽고 건별 재대조가 없는 결함을 잡는다). 변경 이후 건은 발송되지 않아야 통과.
5. **덤프 대상 = transport 호출 전체 인자**(URL·헤더·body). body 만 보면 대상 계정(`Authorization` 헤더의 API 키)·답장 주소 헤더 변경을 못 잡는다. **`Idempotency-Key` 는 비교에서 제외**한다(매 호출 달라지는 값).
6. **판정** — 변경 후 transport 에 도달한 payload 가 승인 시점 baseline 과 다르면 실패(전송이 막혀 transport 호출이 0건이면 통과).
7. **대조군(시험이 죽어 있지 않다는 증거)** — 승인 검사를 일부러 무력화(항상 통과)한 상태에서 입력을 바꾸면 payload 가 실제로 달라지는 입력이 1개 이상 있어야 한다. 없으면 이 시험은 아무것도 못 재는 것이므로 실패다.
8. **선행 순서(기존 출하본을 고칠 때)** — 결함이 있는 상태에서 이 시험이 실제로 실패하는지를 먼저 확인하고, 수정 뒤 통과를 확인한다(첫 실검증).

**`IRREVERSIBLE` 스위치 점검** — `test_irreversible_flag_matches_tools` 는 **코드 신호만**(`engine._ACTIONS` 의 비가역 액션)으로 판정해, 비가역 액션이 있는데 `IRREVERSIBLE=False` 이면 실패한다. plan.md 는 파싱하지 않는다(표 형식·표기가 제각각이라 오탐). plan.md §2 도구 표의 비가역 도구 유무 ↔ `IRREVERSIBLE` 일치는 V1 이 `templates/V1_지시서.md` 「`IRREVERSIBLE` 스위치 일치」 줄로 사람이 판정한다. `engine._ACTIONS` 에 `irreversible: True` 액션이 하나라도 있으면 `IRREVERSIBLE=True` + 차분 결속 시험 채움이 필수이며 면제 장치는 없다. 외부 효과 없는 로컬 산출물 생성 같은 동작은 `irreversible` 표시를 하지 않는다(비가역 = 게시·삭제·결제·전송).

뼈대: `templates/test_gates.py` 「3b++ 차분 결속 시험」. 비가역 도구가 있으면 `IRREVERSIBLE = True` 로 바꾸고 ▼ 도메인 함수(fake transport 주입·승인 호출·승인 유효 판정)를 채운다 — 채우지 않으면 `NotImplementedError` 로 빨갛게 남는다(skip 으로 숨지 않는다).

## 3. 금지
- **항진·skip 잔존(★V4.12)** — 비가역 도구 대응 시험이 `pytest.skip` 뼈대로 남거나 절대 실패하지 않는 항진명제(`assert x is True` 를 방금 표에서 읽은 값에 대고 하는 식, `h == h`, payload 를 안 보는 시험)면 그 시험은 없는 것과 같다. **1차 필터**로 `grep -nE "pytest\.skip\(|pytest\.mark\.(skip|xfail)|assert True|NotImplementedError" _개발자료/tests/test_gates.py` 를 돌려 나온 줄을 V1 이 하나씩 본다 → 정당한 `skipif`(GUI 트랙 아님 등 사유가 적힌 것)가 아니면 V1 반려. **한계**: grep 은 `skipif`·`xfail` 조합, `h==h` 변형, payload 를 안 읽는 시험을 못 잡고 정당한 `skipif` 는 오탐한다 — 실효 검증은 §1b 차분 결속 시험이 실제로 도는가 + V1 의 시험 코드 읽기다.
- **글자가 근처에 있는가 시험** — 소스를 고정 글자 수로 잘라 낱말을 찾는 시험은 호출을 지워도 통과한다. 함수 본문(중괄호 짝)·라우트 경계로 자른다. 정규식 역슬래시는 `chr(92)` 로.
- **실 state 에 쓰는 시험** — `monkeypatch` 로 `store.STATE_PATH`·`BACKUP_DIR` 를 임시 폴더로 돌린다.
- **미확인을 통과로** — probe 의 `found=None` 을 False/True 로 단정하는 시험 금지.
- **더미 치환 주의(설계상 정상 — 결함 아님)** — `test_gates.py` 의 `test_output_filter_blocks_forbidden_claims` 2건(parametrize)은 `{{도메인 금지 문구 N}}` 과 `guard.py` 안의 실제 금지 문구를 **전부 같은 더미값**으로 치환했을 때만 실패한다(금지문구=치환문구가 되어 필터 로직과 기대값이 동시에 무너짐). 도메인 값을 채워 금지문구≠치환문구가 되면 통과한다 — 뼈대 그대로 돌리는 스모크 단계에서만 나오는 현상이니 고치지 말 것.
