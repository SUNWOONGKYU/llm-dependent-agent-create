## 실행 환경
- Windows 11, Python 3.14. 모든 python 실행은 `PYTHONUTF8=1` 환경변수로(한글 경로·출력).
- 작업 디렉터리 `{{에이전트 폴더}}`. 서버 기동은 `시작.bat` 그대로(포트 {{포트}}, 기존 프로세스 자동 교체). 토큰은 `%LOCALAPPDATA%\{{agent-slug}}\token`, `http://127.0.0.1:{{포트}}/?t=<토큰>` 으로 열면 쿠키가 붙음. 자동 오픈을 막으려면 `NO_BROWSER=1`.

- Playwright 설치되어 있음(`_개발자료/_qc/smoke_ui.py`(GUI 트랙 필수 산출물 — templates/smoke_ui.py 복사본) 참조). 브라우저 클릭 검증은 여기서.
