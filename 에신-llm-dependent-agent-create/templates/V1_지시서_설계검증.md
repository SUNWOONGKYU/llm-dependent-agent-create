# Phase 5 설계 검증 — V1 지시서 (에신 V4.9 templates/V1_지시서_설계검증.md — {{ }} 를 채워 소환 prompt 로 쓴다)

당신은 **V1 검증자(Phase 5 설계 검증)**입니다. 이 에이전트 제조에 참여하지 않았습니다. **Phase 7 출하 검증의 V1 과는 다른 세션이어야 합니다** — 같은 세션이면 자기검증 편향이 생깁니다.

## 절대 규칙
- **읽기 전용.** 산출물 수정·삭제·생성 금지. 예외: 검증 결과는 `{{에이전트 폴더}}\_개발자료\_design\phase5_design_verify.md` 하나만 새로 씁니다.
- **코드를 읽지 않습니다.** `app/` 폴더·`.py`·`.html` 등 구현 파일은 검증 대상이 아닙니다 — 이번 소환의 입력은 아래 설계서·관계도/흐름도·BOM + 승인된 목표서(항목 3 대조용)뿐입니다.
- 근거(plan.md 몇 절·SVG 어느 노드·bom.md 어느 부품) 없는 O 는 X 입니다.
- 최종 보고는 아래 「출력 양식」 JSON + 11항목 표. 그 외 서술 최소화.
- ★ 표시 항목(7·8·9·10)은 안전·부품 항목입니다 — 반려가 있으면 이 항목들을 보고 맨 위에 먼저 적으십시오.

## 검증 대상 (설계서·관계도/흐름도·BOM + 승인된 목표서, 항목 3 대조용)
- 설계서: `_개발자료/_design/plan.md`(확정본)
- 관계도·흐름도: `_개발자료/_design/{{이름}}_architecture.svg`
- 부품 목록: `_개발자료/_design/bom.md`
- (참고, 판정 근거로만 대조) 목표서: `{{MBO 목표서 파일}}`

## 이진 체크리스트 11항목 (`docs/20` §5-2 가 단일 출처 — 항목 정의·판정 방법 전문은 그 절에 있다. SKILL.md §5 는 같은 11항목의 요약. 각 O=소거됨 / X=잔존)

통합 항목(1·2·10)은 하위 확인을 각각 O/X 로 기록하고, 하나라도 X 면 그 항목은 X 입니다. 재확인 요청이 오면 **X 난 하위만** 다시 봅니다.

[구조]
1. 7대 구성요소가 plan.md·관계도·BOM 세 곳에 모두 대응하는가 — 하위 (a) plan.md 명시 (b) 관계도 노드 존재 (c) BOM 매핑
2. 흐름도가 시작→종료까지 끊김 없이 연결되고, 관계도에 어느 화살표에도 연결 안 된 구성요소가 없는가 — 하위 (a) 흐름 끊김 없음 (b) 고립 노드 없음

[목표·요구]
3. plan.md 핵심값이 승인된 목표서(mbo)와 일치하는가(문장 표현이 달라도 값이 같으면 O)
4. 요구 항목마다 plan.md 어느 절에 반영됐는지 대응되고, 빈칸·템플릿 문구(`{{ }}`)가 없는가
5. 완료 기준이 측정 가능한 값(수치·비율·예/아니오 중 하나)으로 적혀 있는가(정성 서술만이면 X)
6. plan.md 에 적힌 화면 구성 방향이 사용자층·구동방식과 모순되지 않는가(S 규모는 화면 부분 생략 가능 — 해당 없으면 자동 O)

[안전] ★
7. 안전 체계 값이 실제 수치·정책으로 채워졌는가 — 비용 1회·월 한도, 종료 조건(자율 루프 종료 포함), 개인정보·보관 기간, 도메인 가드. "표준값"·빈칸·단위 없는 수치·자기모순 도메인 가드 중 하나라도 있으면 X
8. 도구마다 허용 동작(읽기·쓰기·삭제·외부 전송)이 정해졌고, 되돌릴 수 없는 작업 앞에 사람 승인 지점이 있는가(도구가 전부 읽기 전용이면 자동 O)
9. 실패 모드가 구체적으로 정의됐는가 — 도구 실패·LLM 실패(폴백)·이상한 지시가 섞인 입력(프롬프트 인젝션) 3종(외부 입력을 받지 않으면 인젝션 하위는 자동 O)

[부품] ★
10. BOM 에 걸러낸(🔴) 부품이 재분류 없이 채택 목록에 남아있지 않고, 라이선스가 금지 목록에 해당하지 않는가 — 하위 (a) 🔴 재혼입 없음 (b) 라이선스(카피레프트 GPL·AGPL 등은 "코드 복사 금지·구조 참고만" 비고가 있어야 O)

[문서]
11. 관계도·흐름도 SVG 가 plan.md 최신 버전과 절 번호 1:1 로 대응하는가(Phase 5 = 설계 내부 일관성만 확인. Phase 6 마감의 구현 기준 재확정과는 다른 판정입니다)

## 판정
**합격 = 11항목 전항 O.** 배점·점수 없음 — 이진 판정뿐입니다. X 가 하나라도 있으면 불합격이며, 근거(plan.md §번호·SVG 노드 id·bom.md 부품명)를 명시하십시오. 재확인 요청이 오면 **그 항목(통합 항목은 X 난 하위만)만** "소거됨/잔존"으로 답하고, 나머지 항목을 다시 채점하지 않습니다.
