> 에신 V4 templates/CLAUDE.md. 에이전트 폴더 루트에 둔다. 이 파일은 «다음에 고치는 사람»이 망가뜨리지 않게 하는 문서다 — 설명이 아니라 금지·함정·명령을 적는다.

## 이 프로젝트에서 절대 어기지 말 것

1. **자동 확정 금지** — {{제출·확정·발송 같은 되돌리기 어려운 동작}}을 코드가 하지 않는다. 산출물은 전부 "{{사람}} 검토 전 초안".
2. **근거는 {{규칙·지침 N종}}** — `app/skills/*.md` 가 단일 출처. 불확실하면 「확인 필요」로 표기하고 추정하지 않는다.
3. **개인 식별자 가명화** — LLM 전송 전 {{성명·연락처·…}}를 마스킹한다. 새 입력 경로를 추가하면 `engine._names_from_fields` 에 등록한다(빠뜨리면 실명이 샌다). 이름 목록은 `state.pseudonym_names` 에 저장해 재시작 후에도 유지한다.
4. **저장·기록은 로컬 전용** — `127.0.0.1` 바인딩 고정. 외부 전송 경로를 만들지 않는다. 밖으로 나가는 것은 {{예: DOI·조문 표기}}뿐.
5. **화면은 마지막 하나만** — 새로 띄우면 기존 서버·창을 전부 종료한다(`terminate_previous`).
6. **결정론 우선** — {{수치·계산·판정 항목}}은 코드로 계산한다. LLM 에 맡기지 않는다.
7. **자기검증 금지** — 만든 사람이 자기 결과를 통과시키지 않는다. "파일이 생겼다"가 아니라 화면·문서를 열어 확인한다.
8. **`시작.bat` 에 한글을 넣지 않는다** — cp949 콘솔에서 깨진다. 한글 안내는 `app/ui.py` 가 출력한다. **cmd 블록 안 괄호 금지**(`echo (…)` 가 블록을 조기 종료시킨다).
9. **폴더 이름을 `시작.bat` 에 적을 때는 ASCII 만** — 본체 폴더가 `app` 인 이유.
10. **LLM 은 두 자리** — 작업·1차 검증 = Claude Code CLI, 2차 검증 = Codex CLI. 다른 CLI 를 끼워 넣지 않는다. API 키 0.
11. **미확인 ≠ 통과** — 판정하지 못한 것을 「이상 없음」으로 그리지 않는다. 화면 칩은 준비됨 / 확인하는 중 / 확인 못 함 / 없음 네 값.
12. **상태를 지우는 경로는 확인 + 백업** — 초기화(새 시작) 전에 `store.backup_state()` 가 돌고, 단계가 바뀔 때마다 스냅샷이 남는다.

## 이 프로젝트에서 실제로 반복된 함정
1. **만들어 놓고 안 쓰는 코드** — 검증기를 만들면 호출부까지 같이 만든다. {{사례}}
2. **거짓 안심** — 판정하지 못한 것을 문제없음으로 그린 것. 미확인·미대조는 통과가 아니다. {{사례}}
3. **백엔드 원칙이 화면까지 안 이어짐** — 반환에 새 키를 만들면 `uicontract.py` 와 화면을 같이 고친다. 시험이 «계약에 없는 키»를 잡는다.
4. **UTC 날짜** — `toISOString()` 은 UTC. 한국 오전엔 하루 밀린다. `todayLocal()` 을 쓴다.
5. **글자가 근처에 있는가 헛시험** — 소스를 고정 글자 수로 잘라 낱말을 찾는 시험은 호출을 지워도 통과한다. 함수 본문·라우트 경계로 자르고, 새 시험은 일부러 망가뜨려 빨간불이 나는지 본 뒤 넣는다.

## 주석 쓰는 법
확인한 것과 추정한 것을 갈라 적는다. 수치를 코드에 넣을 때는 출처(규칙·조문·실측)와 확인 날짜를 주석에 같이 적는다.

## 고칠 때 반드시

```
set PYTHONUTF8=1
python -m py_compile app/*.py
python -m pytest _개발자료/tests -q -p no:cacheprovider     # 전량 통과
powershell -ExecutionPolicy Bypass -File _개발자료/tools/verify_windows_adapter.ps1 -ProjectDir . -HumanFacing
```
그리고 **`시작.bat` 을 눌러 화면을 실제로 띄워 눈으로 확인한다.** "파일이 생겼다"는 확인이 아니다.

**사용자에게 보내기 직전에는:**
```
python _개발자료/tools/출하_정리.py --지움      # 시제 데이터·시험 데이터 삭제. 순서는 「시험 → 정리 → 포장」
```
